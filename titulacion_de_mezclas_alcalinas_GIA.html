Guía de Mezclas Alcalinas

Esc. 4044 Casale - Química Analítica

  1. Etapa 1 (Fenolftaleína): Abre la bureta y titula la muestra rosa hasta que vire a incoloro / rosa tenue. Cierra la bureta para registrar V1.
  2. Etapa 2 (Verde de Bromocresol): Se añadirá automáticamente el 2° indicador (azul). Abre la bureta y continúa titulando hasta lograr el viraje a verde (punto final). Cierra para registrar V2.
  3. Análisis cualitativo:
    • Si V1 > ½ V2 → NaOH + Na2CO3
    • Si V1 < ½ V2 → Na2CO3 + NaHCO3
  4. Cálculos: Utiliza los volúmenes V1, V2, V muestra y C ácido para determinar las molaridades de cada componente.
